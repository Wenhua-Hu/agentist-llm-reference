## 测量范围

short 提取 1 条记录，精确 512 个 chat-template 输入 tokens，输出上限 96；long 提取 8 条编号记录，精确 1024 输入 tokens，输出上限 384。两组都用固定自然语言前缀，严格验证 JSON 字段、类型、值和原始记录顺序。编号只说明顺序；答案不含编号。JSON 模式约束格式，不提供标准答案或保证语义正确。

每个 profile 测量 short/long × 并发 1/4/8/16，每格 3×16 请求，预热另记。closed-loop 请求、共享前缀允许复用，不能把这些数字宣传成任意 prompt 的聊天吞吐。输出 token/s 只计算正确且完整响应的可见文本重分词数；TTFT/TPOT/E2E 使用客户端时钟，SSE 事件不是单个 token，TPOT 是代理值。失败请求留在分母，失败的部分输出不算有效吞吐。

KV 原理验证另用固定 1.5B FP32；Prefix 用实际 7B 服务；Attention 是合成张量 SDPA math/flash 对照。它们不能与最终 FlashInfer 服务吞吐混称一个实验。性能压测保留真实鉴权、余额/token 预占及持久化账本。
